## 2024-05-30 - Focus Management on Ephemeral Action Buttons
**Learning:** When building accessible React UI components where clicking a button unmounts the button itself (e.g., a "Clear search" or "Clear filters" button), focus is lost and resets to the document body. This creates a confusing and broken experience for screen reader and keyboard users, forcing them to re-navigate the entire page to get back to where they were.
**Action:** Use a `useRef` to track a logical fallback element (like the associated search `<input>`) and explicitly call `.focus()` on it inside the `onClick` handler right before the state update that causes the button to unmount. This ensures a seamless keyboard navigation experience.
